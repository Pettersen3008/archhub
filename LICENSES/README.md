# Third-party notices

The frontend embeds DM Sans, Manrope and IBM Plex Mono through Fontsource.
Their original font license notices are included here and installed with the
Arch application package. These font licenses remain distinct from ArchHub's
GPL-3.0-only source license.

Other Rust and JavaScript dependencies retain their own licenses. Exact resolved
versions are recorded in Cargo.lock and bun.lock; their source distributions
carry the corresponding notices. Review licenses when adding dependencies.
